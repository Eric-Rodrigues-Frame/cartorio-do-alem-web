# Cartório do Além (versão web de teste)

Jogo do Eric Rodrigues e Caio D'Andrea, feito na Godot.

O jogo publicado fica no último **Release** (`web.zip`). A automação em `.github/workflows/publicar.yml`
publica esse zip no GitHub Pages sempre que sai um Release novo.

Pra atualizar: exporte o preset "Web" da Godot, zipe o conteúdo da pasta (index.html na raiz do zip)
como `web.zip` e crie um Release novo com ele.
